# Frontend Changes

**Always include screenshots in PRs for frontend changes.** This helps reviewers see the UI behavior and visual design.

## Visual Assets & Documentation

For frontend features, create visual documentation files to supplement PR screenshots:

- **COPY_BUTTON_DEMO.html** - Interactive demonstration of UI states with theme colors
- **COPY_BUTTON_FEATURE.md** - Detailed technical documentation of implementation

These files can be viewed in a browser to show button state transitions, visual hierarchy, and component behavior.
