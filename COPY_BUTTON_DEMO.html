How it works: Click the clipboard icon next to the fullscreen button to capture the current plot as a PNG image. The image is automatically written to your system clipboard (or downloaded as a fallback for older browsers). The generated PNG includes a clean footer bar showing ARTIQ branding, the run ID (e.g., #1042), and a timestamp. The button shows a green checkmark for 1.5 seconds after the copy succeeds, then returns to the clipboard icon.
